# SplitIt - 50/30/20 Budgeting

SplitIt is a mobile-first personal finance application designed to help you manage your money using the simple yet effective 50/30/20 rule.

## 🚀 Key Features

- **Automatic Budgeting**: Instantly splits your income into three core categories:
  - **50% Needs**: Essential living expenses (Rent, Utilities, etc.)
  - **30% Wants**: Personal spending and lifestyle choices.
  - **20% Savings**: Future-proofing and financial goals.
- **Savings Pool**: Tracks your cumulative savings, combining your 20% automatic allocation with manual transfers and additions.
- **Transaction Tracking**: Real-time updates to your remaining budget as you log expenses.
- **Visual Analytics**: Monthly spending trends and category-based breakdown charts.
- **Multi-Currency Support**: Switch between USD, EUR, and RON.
- **Local Data**: All data is stored locally on your device for privacy and offline access.

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **Mobile Wrapper**: Capacitor (Build for Android)
- **Charts**: Recharts
- **Icons**: Lucide React

## 📱 Getting Started (Development)

1. **Install Dependencies**:
   ```sh
   npm install
   ```
2. **Run Dev Server**:
   ```sh
   npm run dev
   ```
3. **Build for Android**:
   ```sh
   npm run build
   npx cap sync android
   ```
